# Bulldogs OS — frontend app (`app/`)

Public recruitment site + admin shell for the Denver Bulldogs (plan P0.1–P0.2, Sprint 0/1).
Vite + React 18 + TypeScript + TanStack Router (file-based, `src/routes/`) + Tailwind CSS v3.4 +
`@insforge/sdk`. Backend: InsForge project `denver-bulldogs` (see repo-root `AGENTS.md`,
`DECISIONS.md` D2/D3).

## Setup

```bash
cd app
npm install
```

Environment: copy the InsForge dev-project values from the repo-root `.env.local` (gitignored):

```bash
# from repo root
grep -E '^NEXT_PUBLIC_INSFORGE_(URL|ANON_KEY)=' .env.local \
  | sed -e 's/NEXT_PUBLIC_/VITE_/' > app/.env.local
```

Mapping (Vite reads `app/.env.local` — see `.env.example`):

| `app/.env.local`         | comes from root `.env.local`   |
| ------------------------ | ------------------------------ |
| `VITE_INSFORGE_URL`      | `NEXT_PUBLIC_INSFORGE_URL`     |
| `VITE_INSFORGE_ANON_KEY` | `NEXT_PUBLIC_INSFORGE_ANON_KEY`|

Never commit real keys (`.env.local` is gitignored). The anon key is public by design — backend
RLS decides what it can read/write (anon gets `SELECT` on published public `events` only).

## Run

```bash
npm run dev        # http://localhost:5173
npm run build      # tsr generate (route tree) + vite build → dist/
npm run preview    # serve the production build
npm test           # vitest (unit tests for form validation / UTM parsing)
npm run typecheck  # generate route tree + tsc --noEmit
```

## Routes

| Route     | Purpose                                                                 |
| --------- | ----------------------------------------------------------------------- |
| `/`       | Landing (plan P0.1): hero promise, next confirmed session (live from `events`), what to bring, club culture, men’s/women’s/mixed pathways, privacy footer |
| `/signup` | Enquiry form (plan P0.2): required firstName/email/phone/consent, optional rest, honeypot, UTM capture, idempotency key; submits via edge function `submit-enquiry` |
| `/thanks` | Confirmation: next session re-fetched + "a volunteer will be in touch" |
| `/admin`  | Shell: InsForge auth sign-in → role check (`user_roles`) → `action_queue` table |

## Notes

- `src/routeTree.gen.ts` is generated by `tsr generate` (TanStack Router CLI) at dev/build time —
  gitignored, do not edit.
- `vercel.json` adds the SPA rewrite (`/(.*) → /index.html`) per the InsForge skill guidance for
  React SPA deployments.
- Club theme tokens (navy / burgundy / gold) live in `tailwind.config.js`; pages are mobile-first.
- Synthetic data only — never point this app at real personal data or send real emails from it.
